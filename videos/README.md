Add looping exercise demonstration videos here.

Name each MP4 after the exercise `folder` value in `src/data.js`, for example:

- `Goblet_Squat.mp4`
- `Dumbbell_Floor_Press.mp4`
- `Bent_Over_Two-Dumbbell_Row.mp4`

The app will automatically try `/Lift-Log/videos/<folder>.mp4` first. If the video is missing or fails to load, it falls back to the existing two-frame image demo.

Recommended format:

- MP4/H.264
- muted, 3-8 second loop
- portrait or square crop
- light/clean background when possible
